## `tls.protocol_version`

Tests whether the proxy still accepts deprecated protocol versions alongside modern ones, by forcing a handshake at each deprecated version: TLS 1.0 and 1.1 through `crypto/tls`, and SSL 3.0 through a raw ClientHello since `crypto/tls` no longer implements it. Accepted versions are reported together as one observation, code `protocol.legacy_enabled`.

Per-CVE findings (Heartbleed, DROWN, ROBOT) are not probed: they need exploit-specific handshakes, and every affected deployment also enables a legacy protocol or suite reported here.

**Remediate:** disable TLS 1.0/1.1 (and SSLv3) in the proxy's TLS configuration; require TLS 1.2 or later.

## `tls.cipher_strength`

Inspects the negotiated cipher suite for missing forward secrecy (non-ECDHE/DHE key exchange on TLS ≤ 1.2), and separately forces handshakes offering only weak cipher suites to test whether the server still accepts them: RC4, 3DES and NULL through a raw ClientHello, the other suites Go marks insecure (CBC mode with SHA-256) through `crypto/tls`. A raw handshake offering only DHE suites reads the Diffie-Hellman group size and flags a group below 2048 bits.

**Remediate:** restrict the cipher suite list to modern AEAD suites with ECDHE key exchange (or rely on TLS 1.3, which is always forward-secret).

## `tls.certificate`

Inspects the leaf certificate presented during the TLS handshake:

- **Chain trust** — independently verifies the presented chain against the system trust store, and tells a self-signed certificate apart from an untrusted chain.
- **Hostname** — flags a certificate not valid for the hostname of the target URL.
- **Expiry** — flags an expired or not yet valid certificate, and separately one expiring within 30 days.
- **OCSP stapling** — flags a handshake with no stapled OCSP response.

**Remediate:** use a certificate from a trusted CA matching the hostname, automate renewal well before expiry, and enable OCSP stapling.

## Skipped targets

The TLS checks share one handshake, `probe.tls_info`, whose result (`probebase.TLSInfo`) is exported for other scanners. When it fails, they are skipped with the reason given by `TLSInfo.SkipReason`: a plain-HTTP target URL, a port that does not speak TLS, or a closed or unreachable port.

## `tls.https_redirect`

Sends a plain-HTTP request to the target and checks whether it's redirected to HTTPS.

**Remediate:** redirect all plain-HTTP traffic to HTTPS (301/308) at the proxy.

## `tls.hsts`

Checks for a `Strict-Transport-Security` response header with a `max-age` of at least 180 days, `includeSubDomains`, and `preload`.

**Remediate:** add `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload` to responses (start without `preload` until you've confirmed every subdomain is HTTPS-only).
