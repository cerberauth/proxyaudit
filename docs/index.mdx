## Quick start

```sh
proxyaudit scan https://proxy.example.com
```

Every check is non-destructive and read-only (single or few requests, no brute-forcing or state mutation). Exit codes are CI-friendly: `0` no findings, `1` findings present, `2` runtime/connection error.
